### 第 4 周 Day 5（2026-08-14）—— 定时调度器 scheduler 完成（零依赖自实现）

- **新增 [src/monitor/scheduler.py](../src/monitor/scheduler.py)**：两层设计，APScheduler 未装（对应周次再 pip），后续可同门面替换：
  - **核心层（确定性 tick 引擎）**：语义严格对齐 D 的 `MockScheduler`（test_monitor_prediction.py TestScheduler 口径）：
    `add_job(name, interval_minutes)` + `tick()` → 返回本步触发的任务名列表；`_ticks` 先自增、`ticks % interval == 0` 触发；
    `run_count` 累计、`last_run` 记录。`tick()` 不执行回调（与 D Mock 一致）。
  - **真实层（墙钟入口）**：`step()` = tick + 回调执行（同步/异步，单任务异常隔离记 `last_error`，不拖垮调度）；
    `run_loop(tick_seconds=60)` 墙钟驱动（1 tick = 1 分钟），下一触发点按**绝对时刻对齐**避免 sleep 漂移累积。
  - **cron 最小解析**（`cron_to_minutes` / `add_cron_job` 便利入口）：仅支持 Config `SCHEDULER_*_INTERVAL` 实际用到的
    `*/N * * * *` 与 `0 */H * * *` 两类，其余明确抛 ValueError（不静默猜）；`add_job(interval_minutes)` 仍是主接口。
  - 注册校验：interval 必须 ≥1 整数（拒 bool/浮点/字符串）；同名任务重复注册覆盖旧任务（对齐 D Mock 的 dict 语义）。
